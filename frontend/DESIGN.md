# Wedding OS 视觉设计规范

## Design Read

这是一个给婚礼总指挥、新人和协同人员长期高频使用的产品工作台，不是营销落地页。视觉语言定义为“高级酒店礼宾体系 + 现代运营指挥台”：稳重、精致、克制、有仪式感，但不能牺牲数据密度和操作效率。

## 设计旋钮

- `VARIANCE = 6`：通过非对称指标区、宽窄面板和礼仪印章形成记忆点，不破坏后台操作秩序。
- `MOTION = 4`：仅保留页面揭示、悬浮反馈、倒计时轨道与主题过渡。
- `DENSITY = 6`：桌面端保持较高数据密度，移动端自动转为单列。

## 核心设计原则

1. **产品优先**：预算、任务、宾客和风险等操作路径始终高于装饰。
2. **单一形状语言**：主面板 16px，重要舞台 34px，输入控件 7-10px；不使用无规则圆角。
3. **单一强调色**：每套主题只使用一个主强调色和一个辅助金属色。
4. **减少卡片嵌套**：大面板内部使用分隔线、留白和排版建立层级，不继续嵌套浮层卡片。
5. **礼仪字体有限使用**：新人姓名、囍字、倒计时等可使用礼仪感衬线字体；业务标题、数据、表格和按钮统一使用清晰无衬线字体。
6. **动效必须解释状态**：进入、切换、聚焦、悬浮和保存状态可以动；纯装饰元素不得持续抢占注意力。
7. **主题共享组件**：六套主题只修改设计令牌、背景材质和少量装饰，不复制业务页面。

## 视觉令牌

- UI 字体：Aptos / Segoe UI / PingFang SC / Microsoft YaHei。
- 礼仪字体：Cormorant Garamond / Songti SC / STSong，仅用于品牌与仪式信息。
- 阴影：使用大范围低透明度阴影和顶部内高光，禁止厚重黑色投影。
- 边框：使用基于文字颜色 10% 左右透明度的 hairline。
- 背景：使用低饱和径向光晕，不使用通用紫蓝 AI 网格渐变。

## 组件规则

- 侧边导航采用暗色礼宾面板，活动项使用左侧光轨，不使用整块高饱和胶囊。
- 顶栏操作按钮保持 40px 高度，主要操作与工具操作视觉权重分离。
- 指挥中心 Hero 采用非对称双栏：左侧新人和场地信息，右侧倒计时印章。
- 四个经营指标使用不等宽网格，避免四张完全相同的模板卡片。
- 数据表格使用粘性表头、细分隔线、行悬浮反馈和明确焦点环。
- 看板任务卡只使用轻微抬升，不使用弹跳或橡皮筋动画。

## 可访问性与性能

- 所有键盘焦点使用可见 `focus-visible` 样式。
- `prefers-reduced-motion` 下关闭进入动画、持续轨道和悬浮位移。
- 颜色不能作为唯一状态信号，状态仍需文字或图标。
- 不新增动画依赖，当前抛光层使用原生 CSS，避免增加桌面端包体积。

## 禁止模式

- 紫蓝渐变作为所有页面默认背景。
- 卡片中继续嵌套卡片。
- 每个标题上方放置同款圆角图标砖。
- 灰色文字直接放在高饱和彩色背景上。
- 大量玻璃拟态、持续漂浮和弹跳动画。
- 为了“高级”而降低正文、表格或状态信息的对比度。
